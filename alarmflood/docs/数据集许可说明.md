## 二、对我们的影响

1. ✅ **本竞赛使用没问题**——AIC 是公益性学科竞赛，属非商业用途；且材料中已按 `BY`（署名）要求
   标注来源与著作权人（见 `THIRD_PARTY.md` 的第三方清单表）。

2. ⚠️ **商业化路径受约束**——`NC` = NonCommercial（非商业性使用）。
   本作品（AlarmFlood Copilot）如进入商业转化，**不能继续使用该数据集或其衍生告警流**。
   商业计划书 / 答辩中必须明确说明这一点：

   > 产品**算法与架构可迁移**，但**数据需替换为客户自有的告警流**。

3. 📌 **D6 的 Loghub 消融实验因此更有价值**——它证明"方法不挑数据源"，
   可弱化作品对单一数据集的依赖，是商业化叙事里的有力支撑。

4. 📌 参赛材料附录表格中应保留**完整许可名称、著作权人与出处链接**。

## 三、另一件需要单独说明的事：告警是我们造的

数据集下载包内**不含任何告警文件**（只有 metric / logs / trace 三类原始数据）。

本项目使用的「告警流」由 `loaders/loader_aiops2021.py` 的 `RULES` 阈值规则对 metric 生成
——**这属于我们的构造，不是数据集原始内容**。

因此**阈值的选择必须单独说明依据**，不能假托"数据集本来如此"。相关依据见：
- `results/data_choices.md` 第三节（规则选型与逐 KPI 校准记录）
- `results/experiments.md`「已结案」块（含"阈值判据"与"单日样本误判"两条方法论教训）
- 复核脚本 `scripts/probe_rule_coverage.py`
